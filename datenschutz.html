Zugriff auf Google Kalender

Jarvis greift nur nach ausdrücklicher Zustimmung des Nutzers über die Google Calendar API auf den Kalender des angemeldeten Nutzers zu. Der Zugriff dient dazu, Termine anzuzeigen, anzulegen, zu ändern und zu löschen.

Verwendung der Daten

Die Kalenderdaten werden ausschließlich für diesen Zweck genutzt. Sie werden nicht an Dritte weitergegeben, nicht verkauft und nicht für Werbung verwendet.

Speicherort

Der Zugriffsschlüssel liegt auf einem Server in Deutschland.

Widerruf

Die Zustimmung lässt sich jederzeit unter https://myaccount.google.com/permissions widerrufen.

Google API Services User Data Policy

Die Nutzung von Daten aus Google-APIs hält sich an die Google API Services User Data Policy, einschließlich der Limited-Use-Anforderungen.
